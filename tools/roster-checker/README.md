# 团员花名册核查工具

给团委用的花名册核查脚本：**把 Excel 花名册和智慧团建系统里的人数、班级、缺失情况对起来**，
输出一份能直接发给学院负责人的清单。

> 实战战绩：某高校 2026 级两个学院 394 人，查出
> 系统里没有 96 人、班级不符 6 人、学号重复 2 人、表格内重复 1 人。

---

## 它解决什么问题

每年新生入学，团委手上会有一份各学院报上来的花名册；智慧团建系统里另有一份。
两边经常对不上：

| 现象 | 后果 |
|---|---|
| 表里有、系统里没有 | 学生团组织关系没转接，评优、转正都会卡 |
| 系统里有、表里没有 | 漏报，材料少人 |
| 两边都有但班级不同 | 转到别的支部去了，没人跟进 |
| 同一人在表里出现两次 | 人数统计错误 |
| 籍贯写成了县、时间写成 `2023/6/1` | 审核不过，要打回重填 |

手工核 400 人，一个人要来回翻两次表，一天也核不完。这套脚本把它变成 5 分钟。

---

## 三条硬规矩（先看这个）

1. **数据不出本机。** 花名册、系统导出、所有输出都在本地，仓库里一个都没有。
   `config.json`、`输出/` 都写在 `.gitignore` 里。
2. **只核对，不修改。** 脚本只读数据、只出报告，不会碰你的原始表格和系统。
3. **系统数据靠你自己导出。** 脚本不会去登录智慧团建——它没有你的密码，也不该有。

## 怎么用

### 0. 准备

- Python 3.8+（`openpyxl`，其余全标准库）
- 花名册 xlsx（各学院分段的那份大表）
- 智慧团建导出的 csv（`团支部,姓名,手机号,职务`）

### 1. 配置

**第一次用，双击 `开始.bat` 会自动弹出配置向导**，跟着问就行，不用手动改任何文件：

```
【1/6】花名册 Excel        ← 可以把文件直接从资源管理器拖进黑窗口
【2/6】智慧团建导出 csv    ← 没有就直接回车跳过
【3/6】年级
【4/6】要核查哪些学院   ← 输入 all 表示全部学院，不用一个个列
【5/6】时间格式规范        ← dot（2008.8）还是 cn（2008年08月）
【6/6】籍贯严格度          ← y/t 严格（不许出现省、市字），n/f 宽松
```

第 6 问会先把代价讲清楚，再让你决定：

```
    严格：浙江丽水 ✅   浙江省丽水市 ❌
    宽松：浙江丽水 ✅   浙江省丽水市 ✅

    提示：实测 394 人里有 85 人（34%）写了省/市字。
    多数团委把它当共性问题，不逐人报，所以默认宽松。
```

配好之后想再改，选菜单里的「10 重新配置」。

> 为什么不做成「手动编辑 config.json」：不是每个人电脑上都装了编辑器，
> 而且 `.json` 的默认打开方式经常被 PyCharm、VS Code 甚至浏览器抢走，
> 双击打开的东西可能跟你想的不一样。问答式最省事。

**喜欢自己动手的**，也可以把 `config.example.json` 复制成 `config.json` 手动编辑：

```json
{
  "roster":  "D:/团委档案/团员花名册-2026级*.xlsx",
  "sys_csv": "C:/Users/你的用户名/Downloads/智慧团建-团员名单*.csv",
  "colleges": ["机械学院", "人工智能学院"]
}
```

'路径支持通配符，有多个匹配时自动取最新的那个——这样系统第一次导出、第二次导出都在下载目录里也不会选错。

> **关于路径分隔符**：Windows 上正斜杠 `/` 和反斜杠 `\` 都行，脚本两种都认。
> 但 `config.json` 是 JSON 格式，**反斜杠在里面是转义符**，手写必须双写：
>
> ```json
> "roster": "D:\\\\团委档案\\\\花名册.xlsx"    ← 反斜杠要写两个
> "roster": "D:/团委档案/花名册.xlsx"          ← 推荐，一个正斜杠就够
> ```
>
> 配置向导保存时会自动把反斜杠换成正斜杠，所以用向导就不用管这件事。
> 手写配置如果只写一个反斜杠，会报 `Invalid \\escape`——脚本会提示你怎么改。'

### 2. 从智慧团建导出名单

系统**没有**批量导出按钮（校级那个"导出直属下级团支部成员"只导出直属支部，
进到学院层级就没有了）。只能用脚本从页面抓：

1. 登录智慧团建 → 团员管理 → 团员列表
2. 点进某个学院，让右侧显示该学院的团支部列表
3. F12 → Console/控制台 → 粘贴 `scripts/0_提取智慧团建.js` 整段 → 回车
4. 跑完在控制台敲两个字 **`导出`** 回车（不用打括号），得到 csv

> 脚本在你**已登录的浏览器**里跑，用的是页面自带的登录态。不需要、也不应该把账号密码交给任何人。

### 智慧团建是三级结构，脚本只在中间那层工作

```
校级        32 个组织（各学院团委、直属团总支、生活园区团工委…）   ← 脚本不在这层
  └ 点「眼睛」进学院
     学院     该学院的支部列表（五十几条，10 条一页）              ← 脚本在这一层 ✅
        └ 点「眼睛」进支部
           支部    团员名单（10 条一页）                          ← 脚本会自己点进去
```

所以**每抓一个学院，要点进去、跑一次脚本**。跑完点「返回上一级」退出来，换下一个学院。
数据会自动累加，最后敲一次 `导出` 拿到的就是所有学院合并后的 csv。

不小心在**校级**那层跑了也不要紧，脚本会提示：

```
现在停在【校级】的学院列表上，脚本不在这一层工作。
请先点进一个学院（点那一行的眼睛图标），让右边变成支部列表，再跑一次。
```

不会抓错数据，只是白跑一次。

**默认只抓 2026 级的学生班**，会自动跳过两类支部：

| 被排除的 | 为什么 |
|---|---|
| `…2026级研究生团支部` | 名字里带「2026级」，但它不是学生班 |
| `…待转接团支部2` | 同上，名字里可能带年份 |

脚本运行时会打印排除了哪些：

```
[抓取] 范围：2026 级
[抓取] 排除：/研究生|待转接/
[抓取] 已排除 1 个非学生支部：
[抓取]    × 机械工程与智能制造学院2026级研究生团支部
```

抓别的年级、或者要改排除规则，粘脚本**之前**在控制台敲一行：

```js
要抓的年级 = ['2027']            // 抓 2027 级
排除支部   = /研究生|待转接|教师/   // 自定义排除规则
```

之前跑过、localStorage 里已经存了研究生支部的数据也不要紧——脚本开头会自动清掉。

### 3. 跑

双击 `开始.bat`，按菜单走；或者直接跑脚本：

```
python scripts\3_核查_表格内.py     # 表格自身的问题
python scripts\4_对账.py            # 和系统对账
python scripts\5_出总表.py          # 出名单（提交版 + 复核版）
python scripts\6_人数统计.py        # 人数 + 缺失名单
python scripts\7_分学院.py          # 按学院拆开
```

## 换学院 / 核老团员也能用

这套脚本不是只给「2026 级新生」写的。换年级、换学院，改 `config.json` 三处就行，不用动代码：

```json
{
  "colleges": [],                    // 空 = 花名册里有几个学院就核几个
  "single_college": "机能学院",       // 单学院表（没有分段）时填这里
  "date_style": "cn",                // 老花名册的 2005年07月 用 cn
  "grade": "2022-2026级"             // 只影响输出文件名
}
```

**两种花名册版式都支持**（`scripts/roster.py` 自动判断）：

| 版式 | 样子 | 例子 |
|---|---|---|
| **分段大表** | 每个学院前有一行学院名，表头在中间 | 全校汇总的 2026 级花名册（9 个学院 2074 人） |
| **单学院表** | 表头在第 1 行，下面全是数据 | 机能学院 503 人（2023~2026 级混在一起） |

读取时按**表头文字**取列，所以列顺序变了、多出「情况注明」这类列都不影响。

**日期两种写法都能认**：

- `date_style: "dot"` → 只认 `2005.7`
- `date_style: "cn"` → 只认 `2005年07月`

另外，Excel 里**真正的日期单元格**（读出来是 `2004-10-01 00:00:00` 或序列号 `38626` 那种）会自动归一化成上面两种写法，不会被误报成格式错误。这一条是拿机能学院的老表试出来的——不改的话，503 人里有十几个明明是对的却全被判错。

**没有智慧团建名单也能跑**：`sys_csv` 留空，脚本会跳过对账，只做表格内核查（籍贯、时间、重复），人数统计里系统相关的列留空，不会写出「缺 503 人」这种误导数字。

## 以后年级换了怎么办

这套脚本**跟年份无关**，不用每年改代码。

班级号的约定是通用的：`261` = 26 级 1 班。到了 2027 级写 `271`、
2028 级写 `281`，脚本靠「专业简称 + 班号」配对，两边自动对上：

```
花名册  智能制造工程271
系统    智能制造工程专业2027级1班团支部
        ↓ 都转成 智造271
        ↓ 匹配
```

实测过 271 / 281 / 293 / 276 这些还没出现的年级，全部能配上。

**抓取时要告诉脚本抓哪一届。** 默认是 2026 级，换法有两种：

**办法一：在控制台先敲一行**（不用改文件，推荐）

```js
要抓的年级 = ['2027']                        // 只抓 2027 级
要抓的年级 = ['2023','2024','2025','2026']    // 近几年一起抓
要抓的年级 = 'all'                           // 所有 20xx 级都抓
```

敲完再粘抓取脚本，脚本开头会打印：

```
[抓取] 范围：2027 级
```

**办法二：改文件里那一行**

```js
// scripts/0_提取智慧团建.js
const _want = ... : ['2026'];     // 把 '2026' 改掉
```

> 注意：花名册和系统里都是「2026级」这种写法，所以这里填的是**四位年份**。
> 「待转接」「研究生」这类支部名里没有「20xx级」，不会被抓进来——需要的话手动点进去跑
> 文件末尾的 `抓取当前支部()`。

**新开的专业**：跑一次 `8_生成简称表.py`，它会把花名册里没配简称的专业列出来，
在 `data/专业简称.csv` 里补一行就行。不补也能用——两边会退化成用专业原名匹配，
只是清单里显示的班级名会比较长。

## 核查哪些项

| # | 项目 | 判定标准 |
|---|---|---|
'| 1 | **籍贯** | 必须「省+市」。`浙江杭州`✅ `浙江遂昌`❌（县）`浙江省温州市泰顺县`❌（多写）。`浙江省丽水市` 默认算合规，见下方说明 |'
| 2 | **系统缺失** | 表里有、系统里查不到 |
| 3 | **班级不符** | 两边都有但班级不同。**先全表找一遍再判定**：在别的班找到 → 班级不符；整个表都没有 → 才算缺失 |
| 4 | **重复** | 同一人出现两次；两人共用一个学号 |
| 5 | **时间格式** | 出生年月、入团时间必须 `2024.9`（到月、点号分隔）。`2023/6/1`、`2024`、`2023,12` 都不行 |
| 6 | **备注为空** | 备注应填政治面貌 |

### 籍贯「带不带省/市字」是个口径问题

有的团委要求**一句里不能出现「省」「市」这两个字**：

```
浙江丽水      ✅
浙江省丽水市   ❌（内容对，但多了区划字）
```

这条默认**不判**，因为实测 394 人里有 **85 人（34%）**这么写，属于共性问题，
逐人列出来没有意义——团委自己也是这么定的。

真要按严格口径统计，在 `config.json` 里打开：

```json
{ "jiguan_strict": true }
```

打开后同一份数据，籍贯问题会从 151 人变成 236 人（多出 85 人全是这类）。
**建议先关着**，等哪天团委说「这个也得治」再打开。

**另外一条：被标黄的、写了情况注明的行，整行都不报。**

花名册的表头写着「情况注明（如有，该名学生信息请用黄色标注」——被标黄的行
（填充色 `FFFFFF00`）和写了情况注明的行，都是团委**已经知道并记录在案**的，
整行跳过，一条问题都不汇总。

除了这条硬规则，脚本还会按关键词做一次兜底判断，防止有人写了注明却忘了标黄：

| 情况注明里出现 | 视为已说明的问题 |
|---|---|
| 籍贯 | 籍贯有误 |
| 出生日期 / 出生年月 / 入团时间 / 入团地点 / 时间 / 日期 | 时间格式错误 |
| 备注 / 政治面貌 | 备注为空 |
| 智慧团建 / 未接收 / 没有账号 / 退团 | 系统缺失类 |
| 原班级 / 转班 / 账号在 | 班级不符 |

关键词表在 `scripts/roster.py` 的 `EXPLAINED_BY`，按学校的实际写法改就行。'

判定口径以团委实际要求为准，不同学校可能不同，改 `scripts/3_核查_表格内.py` 里的函数即可。

## 籍贯怎么判出来的

「遂昌是县还是市」这种事，人肉判断很容易错，所以脚本自带一份**真实行政区划数据**
（省 → 市 → 区县，2978 条，仓库里自带 `data/行政区划.csv`，103 KB，**离线可用**）。

于是它不只说"错了"，还能告诉你该改成什么：

```
浙江省慈溪市      → "慈溪"是县级，应改为"浙江宁波"
四川省盐亭县      → "盐亭"是县级，应改为"四川绵阳"
浙江绍兴绍兴      → 市名重复写了两次
安徽毫州          → 疑似"亳州"（可能写错字）
```

## 专业简称

各学院写法五花八门（`材料科学与工程261班` / `数字媒体艺术专业专升本261班` / 纯 `土木`），
所以有一张可编辑的简称表 `data/专业简称.csv`：

```
学院,专业全称,简称,人数
人工智能学院,计算机科学与技术,计算机,96
机械学院,机械设计制造及自动化,机制,89
```

`8_生成简称表.py` 会扫描花名册自动生成这张表；哪个简称不满意，改 csv 里一个词就生效。
脚本靠它把「花名册的 智能制造工程263」和「系统的 智能制造工程专业2026级3班团支部」对上——
**换一个学院、换一份花名册，不用改代码**。

## 输出什么

```
输出/
  核查结果-表格内问题.xlsx    籍贯/时间/备注/重复
  对账结果.xlsx              缺失/班级不符
  团员花名册有误名单.xlsx     逐人清单（提交给主任）
  团员花名册有误名单-复核版.xlsx  带「应改为」和分类表，自己复核用
  团员人数统计.xlsx          按学院/按班级人数 + 缺失人员名单
  机械学院-2026级团员核查.xlsx  ← 直接发给学院负责人
  数据学院-2026级团员核查.xlsx
```

名单遵循**一人一行**：同一人身上的多个问题合成一句，例如

```
张三  智慧团建无，表格里有，且表格里出现两次
李四  智慧团建无，表格里有，且学号与王五相同
王五  学号与李四相同
赵六  智慧团建上为信计261，与表格不符
```

另外每份学院清单旁边会多一个 `XX-缺失名单.txt`，一行一个名字，
直接贴进下面那个全局搜索脚本就能跑。

## 最后一道验证：全局搜索核对

脚本的「缺失」判断有个天生盲区：**它只能看到有权限展开的团支部。**
如果某个学生挂在待转接、别的学院、往届支部，抓取会报「缺失」，但他其实有账号。

系统自带一个**全局搜索**（校级管理员可见），能按姓名检索全校，正好补这个洞。

### 为什么值得做

实战数据：某学院 29 个「系统里没有」的学生，逐人全局搜索后——

- 27 人查无此人 → 脚本判断正确
- 1 人（只有「备注为空」这条问题）搜到了 → 他本来就不在缺失名单里
- 1 人搜到 **2 条** → 重名或一人两号，需要人工判断

**结论：缺失名单是可信的，不是抓取漏页。**

### 怎么用

1. 跑 `7_分学院.py`，得到 `XX-缺失名单.txt`
2. 登录智慧团建，打开「全局搜索」页面
3. F12 → Console/控制台 → 粘贴 `scripts/9_全局搜索核对.js`
4. 先跑 `全局搜索自检('你的名字')`，确认接口通
5. 把 txt 里的名字贴进 `全局搜索批量` 的 `RAW`，执行
6. 自动下载 `全局搜索结果.csv`

### 结果怎么读

| 搜索结果 | 含义 | 处理 |
|---|---|---|
| 0 条 | 系统里确实没有 | 按缺失上报，补录/转接 |
| 1 条，另一个支部 | 班级不符 | 转接到本班 |
| **2 条以上** | **重名，或一人两号** | **必须问本人** |
| 1 条，年级对不上（比如 2025 级） | 多半是重名 | 按缺失处理，但备注一句 |

### 脚本到这里就结束了

**「重名」还是「一人两号」，脚本永远分不出来**——两个同名的人在不同学院、不同班级、
不同专业，系统里看起来和「一个人挂了两个号」一模一样。

唯一的办法是找到本人核对手机号。这一步必须人来，工具只负责把「有几个号、分别在哪」
列清楚，让问的时候有据可依。

## 已知问题

**① 「幽灵团支部」——系统 bug**

遇到过这种情况：某个支部在**左侧组织树里能点进去、也能看到成员**，但右侧的团支部列表
**根本不显示它**。列表接口和树接口不是同一套查询，建了支部但状态不对就会被过滤掉。

后果：脚本按列表抓，抓不到这个班。

对策：手动点进那个支部，跑 `0_提取智慧团建.js` 末尾的 `抓取当前支部()`，
再把抄到的名字填进 `config.json` 的 `ghost_branches`：

```json
{
  "ghost_branches": {
    "智能制造工程264": ["姓名1", "姓名2", "姓名3"]
  }
}
```

（放在 config.json 而不是代码里，是因为这些是真实姓名，不能进仓库。）

建议同时反馈给系统管理员——这种数据不一致以后还会出事。

**② 系统里没有学号**

智慧团建导出的字段是 `团支部/姓名/手机号/职务`，没有学号。
所以对账只能按姓名匹配，重名会误判。目前做法：姓名相同但学号冲突的单独标"需人工确认"。

**③ 名字打错字查不出来**

系统里写成「陈鸣」、花名册是「陈明」，脚本只能靠模糊匹配提示"疑似"，
最终要人确认。这种错字光看任何一边都发现不了。

## 常见问题

**双击 `开始.bat`，窗口闪一下就没了**

十有八九是**换行符不是 CRLF**。Windows 批处理必须用 CRLF，用 LF 会解析错乱、
直接退出。用 Git 克隆时 `.gitattributes` 里已经写了 `*.bat -text`，不会再被改；
但如果你是用别的工具另存的，可能就变了。

自己检查一句：

```powershell
(Get-Content .\开始.bat -Raw).Contains("`r`n")      # 应该是 True
```

**提示「没有找到可用的 Python」**

Windows 上经常有个坑：`where python` 会先返回一个
`...\WindowsApps\python.exe`，那是微软商店的**0 字节占位符**，跑不起来。

新版脚本会跳过它，按「`python-path.txt` → `py` → 真正的 `python`」顺序找一个能跑通的。
如果还是找不到：

1. 到 <https://www.python.org/downloads/> 安装，**勾选 Add python.exe to PATH**
2. 或者把 `python.exe` 的完整路径写进本目录的 `python-path.txt`，一行就行

**弹出「Windows 已保护你的电脑 / 未知发布者」**

这是 Windows 对"从网上下载的 bat/exe"的常规提醒，不是病毒。
点「更多信息」→「仍要运行」。嫌烦可以右键文件 → 属性 → 勾「解除锁定」。

**双击 `config.json` 打开的是 PyCharm / 浏览器 / 别的什么**

不用管它——**现在的配置是在 `开始.bat` 里问答完成的**，不需要打开 json 文件。
真要手动改，右键 → 打开方式 → 记事本。
