## 关于 02 为什么是"渲染"而不是"截图"

原始截图是从第 42 行开始截的，**没有表头**——在图上补一个表头等于伪造截图，所以改成用真实数据渲染：

* 数据取自 `输出/upload\\\_plan.csv`，行是真实存在的（序号 2 / 3 / 7 / 44 / 48 / 77 / 79 / 96）
* 只做了三件事：加表头、截断过长文字、给状态上色
* README 的图注写的是「按真实数据渲染」，没有假装是 Excel 截图

这样路人一眼能看懂每一列是什么，比原来那张半截图有用。
